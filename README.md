# 🎮 Interactive Web Game Engine  

A lightweight, browser-based game engine built to showcase **real-time interactive game logic**, **state management**, and **2D canvas rendering** — all in a single, zero-dependency bundle.  

🚀 Live Demo: [Play the Game Online](https://mymkgith.github.io/Canvas-Game-Studio/)  

---

## ✨ Key Features  

- 🌀 **Finite State Machine (FSM):** Structured handling of game states *(Menu, Gameplay, Pause, Game Over)*.  
- 🎬 **Custom Render Loop:** Smooth `requestAnimationFrame` updates for frame-independent rendering.  
- 🎮 **Input Controller:** Decoupled keyboard/mouse event listeners for dynamic control.  
- ⚡ **Collision & Physics Engine:** 2D bounding-box collision detection and vector physics.  
- 📦 **Single-File Architecture:** Pure native HTML5, CSS3, and JavaScript bundled without external dependencies.  

---

## 🛠️ Tech Stack  

- 💻 **Language:** JavaScript (ES6+)  
- 🖼️ **Graphics & Rendering:** HTML5 Canvas API  
- 🎨 **Styling:** CSS3  
- 🌐 **Hosting:** GitHub Pages
